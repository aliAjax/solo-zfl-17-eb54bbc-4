# 胶片分镜条核对台 / 胶片修复与试映排期台

两个纯前端本地应用，无需构建，直接用浏览器打开对应 HTML 即可（或在本目录启动静态服务）。

## 文件

- `index.html` / `app.js` / `styles.css` —— 胶片分镜条核对台（片段录入、排序、核对、导出）
- `schedule.html` / `schedule.js` / `schedule.css` —— 胶片修复与试映排期台（本次新增）

## 排期台功能

- **多卷工作单**：每卷有名称、优先级（高/中/低）、截止时间、关联片段；每道工序有类型（清洗/修复/接片/试映）、占用时长、分配的人员或设备、开始时间、前序依赖（可多选）。
- **沿用核对台数据**：点「同步核对台片段」读取核对台 localStorage（`zfl17-film-strip-desk`）中的片段，按编号去重更新；片段库为空且无卷时会按编号前缀自动建卷。
- **自动排期**：按卷优先级、截止时间与卷内依赖拓扑序做 ASAP 贪心排期，同一资源的占用区间自动避开，甘特图按资源分行展示，红色虚线标注各卷截止时间。
- **提交前校验（阻断即阻止锁定/提交，并在面板与行内标明原因）**：
  - 资源跨卷时间重叠（`OVERLAP`，甘特条红框标注，点击问题可定位）
  - 工序结束晚于本卷截止（`OVERDUE`）
  - 循环依赖（`CYCLE`，给出形如 清洗 → 修复 → 清洗 的环路径）
  - 缺失/悬空依赖、违反前序先后（`MISSING_DEP` / `PRECEDENCE`）
  - 未分配资源、未排时间、时长非正、非法时间、非法优先级（`NO_RESOURCE` / `UNSCHEDULED` / `BAD_DURATION` / `BAD_TIME` …）
- **版本锁定与差异**：校验全通过才能锁为不可变快照（v1、v2…，可写备注）；锁定后的所有改动会在左栏实时显示相对最近版本的增/删/改差异，版本卡可查看完整差异表或单独导出该版本。
- **撤销最近一次批量操作**：自动排期、导入等整批操作可一键撤销（按钮上显示可撤销的操作名）。
- **导入 / 导出**：导出 JSON（当前排期 + 全部锁定版本）；导入时校验 JSON 合法性、重复 ID（卷/资源/工序）、文件内同名资源、缺失依赖、循环依赖、非法开始/截止时间、非法时长与优先级、重复或含非法字符的锁定版本标识——任一阻断问题都阻止导入并出报告。通过后所有外部实体重签为本应用生成的安全 id（外部 id 不进入 DOM/选择器），与当前库**同名的资源统一到既有资源标识**，归并后不留未分配工序；整批导入可撤销。
- **双标签页并发**：localStorage 信封（doc + 三方合并基线 base + revision + 已裁决记录）。
  - **同修订号双写也不跳过**：两个标签页从同一基线各自写入相同 revision 时，对端改动照常三方合并，绝不因 revision 相等而丢弃；
  - 只有一方改动的字段、新增的卷/资源/锁定版本自动并入；
  - 一方删除了另一方**未改动**的卷/工序/资源时，合并结果**同步移除，不会自行恢复**；一方删除而另一方仍在修改时，进入「删除/保留」实体级冲突，由用户裁决；
  - 双方改了同一字段且值不同时，页面顶部出现裁决横幅，并排显示两边的值，必须逐条选择后才能保存，**绝不静默覆盖**；裁决结果按「最终值/最终动作」记录，两个标签页视角相反也不会互相翻盘；
  - 无新内容的合并不回写，避免标签页之间无限回声；刷新、重开页面状态持久保留。

数据存于 localStorage 键 `zfl17-film-restore-schedule`。
